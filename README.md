# GuessMoji

**Course:** SEIS 606 – Vibe Coding

**Project:** Project 2

**Team Members:**
- Ezana Asfaw
- Uchenna Obidiegwu

## Project Overview

GuessMoji is an emoji guessing game where players try to guess movies or countries based on emoji clues.

## Project Approach

We selected the Platform Bake-off approach. Each team member will develop a version of GuessMoji using a different AI development tool.

- Ezana: ChatGPT Pro
- Uchenna: Claude Pro

We will compare both versions using agreed evaluation criteria and choose the best features for the final app.

## Project Documentation

This repository will contain the project specification, contract, working agreement, risks and governance, and development documentation.
